# Sapphire Roadmap

## v0.1 — Conversation Foundation (Current)
- Application shell with collapsible sidebar and mobile nav
- Conversation interface with streaming architecture
- Memory center with categories, search, and consent controls
- Projects with tasks, goals, milestones
- Mission Control prototype
- Settings with permissions and approval system
- Command palette (Cmd/Ctrl+K)
- Sapphire visual identity

## v0.2 — Persistent Memory
- Connect Supabase for authentication
- Persistent conversations, memories, projects, goals
- User profiles stored in database
- Row-level security

## v0.3 — Research
- Live web research with sources and citations
- Saved research sessions
- Summaries with key insights

## v0.4 — Tools
- Connect external integrations (Gmail, Calendar, GitHub, etc.)
- Tool registry with permissions
- Real approval workflows

## v0.5 — Voice
- Voice input (speech recognition)
- Voice output (speech synthesis)
- Hands-free interaction

## v1.0 — Mission Control + Agents
- Full multi-agent mission coordination
- Automated workflows
- Computer control with permissions
- Proactive assistance

## Long-term — Personal AI Operating System
- Web, desktop, and mobile clients
- Shared identity, memory, and projects across platforms
- Developer platform
